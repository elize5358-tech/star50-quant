# 星火 Alpha 3分钟演示视频讲稿

## 0:00-0:20 项目痛点

传统指数增强策略在真实市场里经常遇到三个问题：市场风格快速切换，原本有效的因子阶段性失效；模型容易把市场 Beta 当成 Alpha；同时组合风险暴露很难动态控制。结果就是回测看起来不错，但一遇到高波动或风格切换，超额收益就不稳定。

## 0:20-0:50 产品定位

我们做的“星火 Alpha”是一个面向科创50指数增强的 AI 量化平台。它把数据、特征、模型、组合构建、回测评估和风险监控做成一个完整闭环，目标是在控制相对指数风险的基础上，持续寻找可落地的真实 Alpha。

## 0:50-1:30 技术路线

技术路线是“v5 MoE 主模型 + XGBoost 传统树模型对照”。我们用 v5 MoE 动态 Loss 权重版本作为主基准线，用 XGBoost 代表传统树模型能力。

在此基础上，我们引入 MoE 混合专家模型。个股特征，例如短期动量、波动率、均线偏离和价量相关性，会进入牛市专家和熊市专家；市场环境特征，例如指数趋势、指数波动率和截面离散度，会进入 Gate 门控网络。

Gate 会根据当前市场状态，动态决定牛市专家和熊市专家的权重，最终输出每只股票的 Alpha Score。我们的标签不是直接预测个股收益，而是预测剥离指数 Beta 后的 residual_ret，也就是真实 Alpha。当前演示聚焦最终选定的 v5 版本，IC 为 0.0212，ICIR 为 0.1580。

## 1:30-2:10 Demo 展示

在 Demo 中，首页可以看到系统从数据输入、特征工程、XGBoost 对照、Deep Learning MoE、股票打分、组合构建、回测评估到风险监控的完整流程。模型页会聚焦 v5 MoE、XGBoost 和业界优秀参考线的指标对比。

预测结果页展示最近一期 Top 股票推荐，包括股票代码、Alpha Score、排名、推荐权重、风险标记和一句话解释。回测评估页展示 v5 MoE 组合、科创50指数和 XGBoost 组合的净值曲线，同时展示年化收益、超额收益、最大回撤、夏普比率、IC、ICIR 和月度胜率。

## 2:10-2:40 风险管理

风险管理页会展示组合波动率、最大回撤、行业集中度、单票权重上限、换手率和市场 Beta 暴露。系统把这些指标汇总成 0 到 100 的风险评分：0 到 40 是低风险，40 到 70 是中风险，70 到 100 是高风险。当市场波动率较高时，系统会提示降低仓位或提高分散度。

## 2:40-3:00 商业价值

星火 Alpha 的价值在于把 AI 模型真正放进指数增强投研流程，而不是只停留在离线实验。它可以服务于指数增强产品、量化投研平台、公募基金、券商资管和财富管理投顾，帮助机构更高效地完成 Alpha 发现、组合构建和风险监控。
