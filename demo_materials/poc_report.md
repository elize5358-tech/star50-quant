# 星火 Alpha MVP / POC 实验数据说明

## 项目目标

星火 Alpha 面向科创50指数增强场景，构建一个可产品化的 AI 量化投资系统。系统目标不是简单预测股票涨跌，而是在控制相对指数风险的前提下，寻找可转化为组合收益的真实 Alpha。

## 数据来源

当前 MVP 优先读取本地项目已有数据：

- 科创50成分股后复权日线行情：`star50_daily_hfq_data_6yrs.parquet`
- 科创50指数日线行情：`star50_index_daily_6yrs.parquet`
- 已处理特征：`data/processed/star50_features_stage1_preprocessed.parquet`
- XGBoost 调参与回测结果：`results/xgboost_results_20260611_102029.json`
- XGBoost 训练代码：`src/models/xgb_model.py`、`scripts/run_xgboost_complete.py`

若比赛演示环境缺少真实数据，Web Demo 会自动生成 mock 数据兜底，仅用于产品交互展示，不作为正式收益承诺。

## 特征体系

个股特征用于判断“股票自身强弱”，包括：

- `mom_3d`、`mom_5d`：短期动量
- `vol_5d`、`vol_20d`：短中期波动率
- `bias_20d`：相对均线偏离
- `pv_corr`：价量配合程度

市场环境特征用于判断当前市场状态，包括：

- `idx_bias_20d`、`idx_bias_60d`：指数趋势位置
- `idx_vol_20d`、`idx_vol_mom`：市场波动及变化
- `cs_dispersion`：截面分化程度

## 模型方法

MVP 采用“v5 MoE 主模型 + XGBoost 传统树模型对照”的技术路线。

第一层用 XGBoost 作为传统树模型对照，验证量价因子对未来 Alpha 排序的解释能力。

第二层引入深度学习 MoE 混合专家模型，把个股特征输入专家网络，把市场环境特征输入 Gate 门控网络，由 Gate 动态决定不同专家的权重。当前主基准线采用 v5 动态 Loss 权重版本。

## 树模型 Baseline

传统树模型作为基准模型，承担三类作用：

- 给出可复现、可解释、训练成本较低的 Alpha 排序基准；
- 作为 MoE 模型的对照组，帮助评估深度学习是否真正带来增益；
- 为产品 Demo 提供 IC、ICIR、收益、回撤和风险指标对照。

当前 Demo 优先使用 v5 MoE 作为主基准线，并用 XGBoost 作为传统树模型对照。

## 深度学习 MoE 优化点

MoE 的核心优化是“市场状态门控 + 多专家动态融合”。当前演示聚焦最终选定的 v5 动态 Loss 权重版本，其 IC 为 0.0212，ICIR 为 0.1580。

- `expert_bull`：偏强市场专家，更关注动量延续和价量配合；
- `expert_bear`：偏弱市场专家，更关注波动控制和防御性 Alpha；
- `gate`：根据市场环境特征动态分配专家权重；
- 最终输出 `Alpha Score`，用于截面排序和组合构建。

相比静态模型，MoE 更适合应对行情风格切换、因子阶段性失效和波动率状态变化。

## 标签设计

标签不是直接预测个股收益，而是预测通过 Beta 剥离指数收益后的 `residual_ret`，即真实 Alpha。

这更符合指数增强目标：组合收益应来自选股能力，而不是被动承担市场 Beta。

## 回测指标说明

MVP 使用以下指标评估：

- 年化收益：组合长期收益能力；
- 超额收益：相对科创50指数的增强效果；
- 最大回撤：极端亏损风险；
- 夏普比率：风险调整后收益；
- IC：预测值与未来真实 Alpha 的相关性；
- ICIR：IC 的稳定性；
- 胜率：组合跑赢指数的交易日占比。

其中 IC / ICIR 更符合量化选股的排序稳定性评估。

## 风险控制方法

Demo 展示以下风控维度：

- 组合波动率；
- 最大回撤；
- 行业集中度；
- 单票权重上限；
- 换手率；
- 市场 Beta 暴露。

风险评分采用 0-100 分：

- 0-40：低风险；
- 40-70：中风险；
- 70-100：高风险。

## 当前 MVP 边界

- Web Demo 重点展示产品可行性、技术路径和商业落地潜力；
- MoE v5 指标来自当前已确认实验汇总，净值曲线为基于汇总指标重构的 demo 展示序列；
- 部分行业集中度指标在缺少行业分类数据时使用组合权重近似；
- 展示数据不构成投资建议或收益承诺。

## 后续迭代方向

- 接入完整行业分类、财务因子、另类数据和分析师预期；
- 固化 v5 MoE 训练产物并与 XGBoost 进行真实同窗对比；
- 增加组合优化器，支持行业中性、Beta 中性和换手约束；
- 增加在线风险预警、归因分析和投研工作流；
- 打包为面向公募、券商资管、财富管理投顾的指数增强投研平台。

## 初创组价值

初创组 Demo 重点展示“产品可行性 + 技术路径 + 商业落地潜力”。星火 Alpha 可以服务于指数增强产品、量化投研平台、券商资管、公募基金和财富管理投顾等场景。
